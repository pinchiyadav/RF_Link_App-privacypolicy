Privacy Policy

Effective date: November 13, 2025

This Privacy Policy explains how RF Link - Signal Strength, LOS (the "app", "we", "us") collects, uses, and shares information when you use the app. By using the app you agree to the practices described in this policy.

1. Summary

RF Link - Signal Strength, LOS is a radio propagation planning tool. The app:

  • May request your device location to set transmitter/receiver coordinates or to show maps;
  • Stores your input parameters (coordinates, frequency, heights, advanced settings) locally on the device so they are available when the app restarts;
  • Sends the parameters to a remote processing API (your cloud service) to run the propagation calculation and returns results/plots;
  • Can send user messages to a Google Sheet (used as a simple inbox) when you use the “Send Message” feature;
  • Does not collect payment information in this unlocked build (no in-app purchases or UPI payments are processed by the app).

2. Information We Collect

Location information

If you use features that require location (for example choosing transmitter or receiver positions on a map, or using device-based location input), the app will request location permission. Location is used only to populate coordinates and map display. You may deny or revoke location permission at any time; denying permission will not prevent you from using the majority of app features (you can manually enter coordinates).

Input parameters

The app stores your radio planning inputs locally on the device using SharedPreferences (a local storage mechanism). This includes transmitter/receiver coordinates, frequency, antenna heights, advanced parameters, and terrain sampling preferences. These values remain on your device until you change or clear them.

Processing data sent to cloud API

When you run a propagation calculation, the app sends the input parameters to a remote processing endpoint (the cloud API configured in the app) to perform the calculation and return results. The data sent typically includes the numeric parameters required for the radio model. The server returns calculation results and, optionally, plot images (which the app displays). The cloud API is controlled by the app owner and no data is retained after the output is returned via API.

Messages you submit

If you use the “Send Message” or feedback feature, the app stores your message text in a Google Sheet (Sheet2) used by the app owner as an inbox. The message may include your name, subject, contact email/phone if you provide them. These entries are visible to whoever has access to the Google Sheet.

Technical and device information

The app may collect non-personal technical information required for normal operation (app version, OS version, device model). The app does not collect analytics or crash logs unless you have explicitly enabled such a feature.

3. How We Use Your Information

  • To perform radio propagation calculations and display results to you;
  • To pre-fill forms and restore the last-used parameters when you re-open the app;
  • To send your messages to the app owner’s Google Sheet so they can respond;
  • To provide and improve the app’s features and fix bugs when you report them.

4. Sharing and Disclosure

We do not sell your personal information. We may share information with:

  • Service providers that host or process your requests (for example the Google maps elevation API used to get elevation data to run propagation calculations);
  • Google Sheets (the Google account configured in the app) when you submit a message; those sheet contents are accessible to whoever owns the sheet;
  • Law enforcement or government authorities when required by law.

5. Third-party services used

The app integrates with third-party services that have their own privacy policies:

  • Google Maps SDK — used to render maps and map tiles. Google’s privacy policy applies to map usage: policies.google.com/privacy
  • Geolocation APIs — used to obtain device coordinates when you allow location access;
  • Google Sheets API via a service account — used to read/write certain app-controlled spreadsheets for message/remote configuration. The app owner controls the sheet and its access.

6. Payments

This unlocked build does not collect payments, nor does it process payment details. If you are using a different edition of the app that includes purchases, payment information is handled by the payment provider (for example Google Play) and not stored by the app.

7. Data retention

Local input parameters are stored until you change them or uninstall the app. Messages written to the Google Sheet are retained until the sheet owner edits or deletes them.

8. Security

We take reasonable measures to protect your information on the device and in transit (HTTPS for API calls). However, no system is completely secure — avoid sending highly sensitive personal data through the app or in messages to the sheet.

9. Children

The app is not intended for children under 13. We do not knowingly collect personal information from children under 13. If you believe a child under 13 provided information, contact us and we will delete it.
